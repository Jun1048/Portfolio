### 1-2. 분석 배경 및 목적 (2)

□ **선행연구 조사 — 4C 등급체계와 헤도닉 가격이론**

| 연구 | 주요 내용 |
|---|---|
| GIA(미국보석학회), 1950년대 | 4C 등급체계 확립. carat·color·clarity 3요소는 2,000년 이상 된 인도의 전통 감정 기준에서 유래함 |
| Caudill et al. (1997) | 헤도닉 회귀를 다이아몬드 가격에 적용, 캐럿 중량이 가격에 가장 큰 영향을 미치고 cut·color·clarity가 유의한 양(+)의 영향을 준다고 보고함 |
| Brill et al. (n.d.) | 온라인 소매시장 대규모 표본(169,483건) 연구로 다이아몬드 시장가격이 객관적 속성(4C)에 의해 결정되는 헤도닉 가격방정식이 성립함을 확인함 |

□ **헤도닉 가격이론(계수 해석 근거)**

> 여러 특성이 결합된 재화의 가격을 특성별 잠재가격의 합으로 분해하는 이론적 틀임. 이 이론이 있어야 회귀계수를 "캐럿 1단위당 가격", "등급 1단계당 가격"으로 해석하는 근거가 성립함 — 이론이 없으면 회귀계수는 그냥 숫자에 불과함.

Rosen (1974)
Hedonic Prices and Implicit Markets, *Journal of Political Economy* 82(1), 34–55

### 1-3. 분석 범위 · 단위 · 질문

□ **분석 범위**

◎ 특정 시점의 판매 데이터 스냅샷이므로 인과가 아니라 연관을 본다.

| 구분 | 내용 |
|---|---|
| 시간 | 특정 시점의 판매 데이터 스냅샷(시계열 아님) |
| 공간 | 특정 국가·지역 한정 표기 없음, 미국 달러(USD) 표시 시장 기준 |
| 화폐 단위 | 미국 달러(물가조정 여부 불명) |
| 분석 대상 | 라운드 컷(원형 연마) 다이아몬드로 한정된 것으로 판단됨 |

□ **분석 질문(가설 수립)**

| 번호 | 질문 |
|---|---|
| Q1 | 다이아몬드 가격을 좌우하는 요인은 무엇인가(4C vs 물리적 치수) |
| Q2 | 각 요인이 가격에 얼마나 강하게 작용하는가 |
| Q3 | 처음 보는 다이아몬드의 가격을 얼마나 정확히 예측하는가 |
| Q4 | 이 모형을 실제 가격 산정 업무에 활용할 수 있는가 |

#### ⚠️ 확인 불가로 남긴 지점 — 수집 시점과 화폐 기준연도

데이터·문서 어디에도 정확한 수집 시점, 물가 조정 기준연도가 명시돼 있지 않음. 웹 검색으로도 원 수집처(온라인 다이아몬드 판매 플랫폼)의 정확한 시점을 확인하지 못해, 이 두 항목은 **확인 불가**로 남김. 이는 6단계(결론)의 한계점까지 그대로 유지됨.

| Train↔CV 격차 약 7.78% 잔존(임계값 미달로 과적합은 아니나 데이터 노이즈 또는 모형 용량의 한계로 볼 여지 있음) | **중복행 146건의 실체 확인 불가** — 서로 다른 실물인지 단순 입력 중복인지 최종적으로 규명하지 못함(1단계에서부터 유보한 사안이 6단계까지 유지됨) |
| 평균 ±7.4% 수준의 오차 — 개별 물건 가격 확정 용도로는 부적합 | 소수 범주(I1 clarity 1.37%, Fair cut 2.98%) 표본 부족 — 해당 구간 SHAP 추정이 상대적으로 불안정할 수 있음 |
| 블랙박스 해석의 제한 — SHAP은 모형이 어떻게 예측했는지를 설명할 뿐, 현실의 인과관계를 증명하지 않음. **"캐럿이 커서 비싸다"가 아니라 "모형이 캐럿 정보를 크게 활용했다"가 정확한 진술임** | **수집 시점·화폐 기준연도 불명** — 1단계에서부터 확인 불가로 명시했던 사안이며, 이번 결론까지 추가 근거를 찾지 못해 동일하게 유지함 |
| — | 종속변수가 로그 변환돼 있어 모든 오차 지표를 원 단위(달러)로 직접 읽을 수 없음 |

### 6-5. 후속 연구 제안 — 앞 장의 한계 각각에 대응

| 과제 | 대응하는 한계 | 내용 |
|---|---|---|
| ① 중복행 실체 규명 | 데이터의 한계(중복행) | 원 수집처에 다이아몬드 개별 ID나 촬영 이미지 등 추가 식별 정보가 있는지 확인해, 146건이 입력 오류인지 서로 다른 실물인지 규명함 |
| ② 소수 범주 표본 부족 | 데이터의 한계(I1·Fair 등) | I1·Fair 등 소수 범주 구간의 원 데이터 규모를 재확인하고, 표본이 부족하면 해당 구간 해석을 보고서에서 제외함 |
| ③ 추가 변수 확보 | 모형의 한계(오차 ±7.4%) | GIA 감정서의 형광성(fluorescence)·대칭성(symmetry)·연마(polish) 등급 등을 확보해 캐럿·4C 외 영역의 설명력을 보강함 |
| ④ 재현성 검증 | 방법론적 한계 | 매직사이즈 효과와 조건부 프리미엄 패턴이 다른 소매채널·다른 시점의 표본에서도 재현되는지 검증함 |
| ⑤ 인과 해석 불가 명시 | 블랙박스 해석의 제한 | 인과 해석이 필요하다면 SHAP이 아니라 별도의 인과추론 설계(도구변수, 준실험 설계 등)를 적용해야 함 — 이 보고서 전체에서 가장 오해되기 쉬운 지점 |

## 부록: 분석 파라미터 선택 근거 (임의성 점검)

본문 전체에서 "왜 이 데이터값이 이런가"(예: 캐럿 매직사이즈, carat/x/y/z 다중공선성) 유형의 의문점은 각 단계에서 학술·업계 근거로 규명했음. 이 부록은 별개로, **본 분석에서 임의로 정한 파라미터**(예: 이상치 판정 기준, 학습/검증 분할 비율 등)를 별도로 점검한 결과임.

| 파라미터 | 사용처 | 근거 |
|---|---|---|
| **이상치 경계 = 1.5×IQR** | 전 단계 이상치 판정 | Tukey(1977) 제안의 관례적 계수. 통계학계에서 오랫동안 관례로 굳어진 기준이며, 이 데이터에 맞춰 최적화된 값은 아님 |
| **학습:검증 = 8:2 분할** | 4단계 GroupShuffleSplit | 특별한 이론적 근거는 없음. 머신러닝 실무에서 널리 쓰이는 관행적 비율이며, 다른 비율과 비교 검증하지는 않았음 |
| **random_state=42** | 전 모델링 코드 | 순수하게 재현성 확보 목적의 임의 고정값 |
| **5-Fold 교차검증** | 5단계 과적합 진단 | 관행적 선택이며, 폴드 수를 바꿔가며 결과 민감도는 별도로 검증하지 않았음 |
| **매직사이즈 근접(shy) 구간 폭 = 0.05캐럿** | 3단계 is_near_magic_size 생성 | 업계 자료에 정확한 구간 폭이 명시돼 있지 않아 본 분석에서 임의로 설정함. 폭을 바꾸면 플래그 대상 건수(현재 1,079건)가 달라질 수 있음 |
| **과적합 판정 Gap% 임계값 = 15%** | 5단계 신뢰성 검증 | 학술 표준이 아니라 도메인 경험치. 오차가 불가피하게 큰 사회·경제 데이터 회귀에서 통상 15~25%를 경계로 보는 관행을 채택함 |
| **변수 축소 되돌림 기준 = 5%** | 5단계 변수 축소 검증 | 축소 시도 전 미리 정한 규칙이며 학술적으로 고정된 값이 아님. 다만 실측 변화율(15.92%)이 이 기준을 큰 폭으로 초과해, 기준값을 다소 조정해도 판정 자체는 바뀌지 않을 것으로 판단됨 |
| **SHAP·중요도 누적 채택 기준 = 95%** | 5단계 변수 축소 후보 선정 | 채택 변수 수를 정하는 절단선이며, 90%나 99%로 바꾸면 채택 변수 개수가 달라짐 |
| **CatBoost 튜닝 탐색 격자** | 4단계 하이퍼파라미터 튜닝 | iterations{300,600}·depth{6,8}·learning_rate{0.05,0.1}로 좁게 설정함(연산 비용 제약). 더 넓은 격자에서 더 나은 조합이 존재할 가능성은 확인 불가로 남김 |
| **SHAP 분석 표본 크기 = 800건** | 5단계 SHAP 계산 | 검증셋(10,783건) 전체가 아닌 무작위 표본으로 계산함(연산 비용 절감). 전체로 계산 시 근소한 수치 차이가 있을 수 있으나 방향성이 바뀔 정도는 아닐 것으로 판단되며, 전체 재계산으로 직접 확인하지는 않아 확인 불가로 남김 |

**정리**: 통계적 표준 관행(IQR 1.5, 8:2 분할, 5-Fold, log1p)은 임의성이 낮아 재현성이 높은 반면, 매직사이즈 구간 폭·Gap% 임계값·변수 축소 기준·SHAP 채택 컷오프·튜닝 격자 5가지는 본 분석에서 정한 값이며 다른 값을 택했다면 세부 수치가 달라질 수 있음을 투명하게 밝힘. 다만 핵심 결론(캐럿 지배구조, 등급의 조건부 프리미엄, CatBoost 최종 선정)은 이들 파라미터를 상당폭 조정해도 뒤집힐 만큼 근소한 차이가 아니므로 결론의 강건성 자체는 유지되는 것으로 판단됨.
